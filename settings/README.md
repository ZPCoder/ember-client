# Creator-generated settings

Open this directory with **Cocos Creator 3.8.8**. Creator owns the generated
settings below this directory. The repository deliberately does not fabricate
scene or asset metadata; the first editor import must generate `.meta` files,
and a designer must create the named scenes from `docs/EDITOR_BOOTSTRAP.md`.

`settings/v2/packages/project.json` contains only source-controlled project
defaults that are safe to review without the editor.
